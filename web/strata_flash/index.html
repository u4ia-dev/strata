2Install

    
The FM-1's own update path, as Felucca's installer uses it: the firmware running now reads the package and
    starts the update loader, the loader writes the app area only (0x4000–0x92FFF;
    the boot head and your settings' sectors are never written), then the FM-1 restarts into Strata. About a
    minute. Then switch the FM-1 off and on when the page asks: it says Done only when Strata answers again after
    that restart.

    

    

      

      
Do not unplug the FM-1 or switch it off until this page says Done.

      

    

  


  

    
3Test and report

    
Work through the checklist in FLASHING.md (section
    4). On the FM-1, hold HOME 5 s for the SETTINGS; the last page, BENCH, shows the measurements. This reads the
    same figures from Strata's USB serial console, ready to paste back.

    

      
      
      
    

    
Chrome asks for the port: pick the FM-1's (a USB serial device). The loops stop the sound for a
    moment.

    

  


  

    
Going back

    
    
      
  1. To Felucca: its own installer, hugelton.github.io/Felucca. It finds Strata's FM-1: Strata keeps Felucca's update entry and
        its USB name.
    2. 
      
  2. To the official V15: pick M-VAVE's unmodified FM-1.fwsc (checked here by its SHA-256,
        never uploaded), then write it with the same update path. M-VAVE's own updater works too.
    3. 
      
  3. To exactly what you had, or when Strata does not answer: write your backup or the official V15 back by
        the Flipper Zero route (FLASHING.md, section 6).
    4. 
    

    
    

    

      

      

    

  


  

    
If something goes wrong

    
    
      
  • A write stopped (cable, browser): replug and press Find the FM-1 again. The FM-1 stays in update mode
        and the page finishes the write.
    • 
      
  • Strata shows STRATA CRASH: take a photo. It restarts; a second crash within 30 s puts it in backup
        mode by itself, where your backup can be written back.
    • 
      
  • Backup mode by hand, while Strata runs: hold OCT− and OCT+ for 5 s (a
        countdown shows from 2 s). If Windows then reports a USB device it cannot recognise, this way in does not
        work on this computer: use the Flipper Zero route.
    • 
      
  • Strata does not answer any updater (it plays, but Find gets no answer): the Flipper Zero route
        (FLASHING.md, section 6) or the FM-1 Transporter. Both enter backup mode at power-on, whatever the firmware
        does.
