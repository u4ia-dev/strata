Strata USB check

Finds which way the FM-1's USB data fails. Nothing here writes to its flash. Close M-Upgrade and other MIDI apps first, use this one browser tab, work down steps 1 to 4, then copy the log into the conversation.

1The MIDI ports

Lists every MIDI port the browser sees, and picks the FM-1's.

2The FM-1 answering

Sends the identity request the flasher and M-Upgrade send, three times, and logs every message that comes back on any port.

3The computer reaching the FM-1

Plays middle C on channel 1 for a moment. Turn MASTER up and listen.

4The serial console

Opens the FM-1's serial port (Edge asks which: pick the FM-1's), listens 3 s, types help, listens 3 s more, and logs every byte.

5Only if steps 2 and 4 got nothing back

Each button sends one command that makes Strata show UBOOT (USB) and restart, as OCT− + OCT+ does. If the screen shows it, the message reached Strata. Then tell the page what the screen did.
