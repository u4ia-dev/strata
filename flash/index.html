1 / 2Before you start

    
    
      
  • 
        
    A full flash backup (recommended). All 1 MiB, read twice, the two copies identical, checked as an
        FM-1's flash: the way back to exactly what you have now. The install no longer needs one; make one before your
        first Strata and whenever your presets matter. Press Back up now, then put the FM-1 in backup mode the
        Flipper Zero way.
    
        
    The Flipper Zero steps
        
      
          
    1. The Flipper unplugged from this computer: Apps > Tools > FM1 Recovery. The FM-1 switched
            off, a USB-C data cable from the Flipper to the FM-1.
      2. 
          
    2. OK on the Flipper, then switch the FM-1 on. At Move FM1 cable to PC now, move the cable to
            this computer without switching the FM-1 off.
      3. 
          
    3. If Windows offers to format a disk: Cancel. This page reads it by itself, then lets it go.
      4. 
        
    
        
    
          
    
        
        
    Asking this page's server about backups…
    
        
    
          
    Another way into backup mode, where it works: this button asks the firmware running now to go there (the
          soft key). It does not reach backup mode on every computer; the Flipper's way works at power-on, whatever
          the firmware does.
    
          
    
          
    
            
    The FM-1 will stop its firmware and wait for jl-uboot-tool. Nothing is written.

2 / 2Install

    
The FM-1's own update path, as Felucca's installer uses it: the firmware running now reads the package and
    starts the update loader, the loader writes the app area only (0x4000–0x92FFF;
    the boot head and your settings' sectors are never written), then the FM-1 restarts into Strata. About a
    minute. Then switch the FM-1 off and on when the page asks: it says Done only when Strata answers again after
    that restart.

    

    

      

      
Do not unplug the FM-1 or switch it off until this page says Done.

      

    

  



  

    
Going back

    
    
      
  1. To Felucca: its own installer, hugelton.github.io/Felucca. It finds Strata's FM-1: Strata keeps Felucca's update entry, and its USB
        name has "FM-1" in it, which the installer looks for.
    2. 
      
  2. To the official V15: pick M-VAVE's unmodified FM-1.fwsc (checked here by its SHA-256,
        never uploaded), then write it with the same update path. M-VAVE's own updater works too.
    3. 
      
  3. To exactly what you had, or when Strata does not answer: write your backup or the official V15 back by
        the Flipper Zero route (the manual).
    4. 
    

    
    

    

      

      

    

  


  

    
If something goes wrong

    
    
      
  • A write stopped (cable, browser): replug and press Find the FM-1 again. The FM-1 stays in update mode
        and the page finishes the write.
    • 
      
  • Strata shows STRATA CRASH: take a photo. It restarts; a second crash within 30 s puts it in backup
        mode by itself, where your backup can be written back.
    • 
      
  • Backup mode by hand, while Strata runs: hold OCT− and OCT+ for 5 s (a
        countdown shows from 2 s). If Windows then reports a USB device it cannot recognise, this way in does not
        work on this computer: use the Flipper Zero route.
    • 
      
  • Strata does not answer any updater (it plays, but Find gets no answer): the Flipper Zero route
        (the manual) or the FM-1 Transporter. Both enter backup mode at power-on, whatever the firmware
        does.
