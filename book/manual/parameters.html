Parameter reference

Parameter reference

Every parameter a Strata sound stores, by section, as the screen shows it. Mod: the matrix (and the assign window) can move it. CC: the MIDI control change that sets it without MIDI LEARN (none: -). The drums, the looper and the settings keep their own values: see their chapters.
