# Cheat sheet

Every button, on one page. **Twice**: a second press within 300 ms. **Held**: held past the HOLD time (400 ms by
default). **+ OCT+ / + OCT−**: hold the button, press OCT+ or OCT−. **+ OCT− 5 s**: hold the button and OCT− for five
seconds (a countdown shows from 2 s; let go of OCT− to stop it).

## The menu buttons

| Button | Once | Twice | Held | + OCT+ | + OCT− | + OCT− 5 s |
| --- | --- | --- | --- | --- | --- | --- |
| <kbd>HOME</kbd> | HOME (SOUND, MIX 1-4, MIX 5-8) | SETTINGS | the help map; 5 s: DEBUG | the next sound | the sound before | |
| <kbd>EDIT</kbd> | OSC A, OSC B, SUB, NOISE, FILTER, MATRIX (a drum track: DRUM, KIT) | the oscillator's wavetables (a drum track: the drum presets; from KIT or HOME, the kits) | | the source or filter shown on | off | the module shown reset |
| <kbd>ENV</kbd> | ENV 1, ENV 2 | the assign window: an envelope or a macro onto a knob | | | | the envelope shown reset |
| <kbd>LFO</kbd> | LFO 1, LFO 2 | the assign window: an LFO onto a knob | MOMENTARY | a point added | the point picked deleted | the LFO shown reset |
| <kbd>FX</kbd> | the chain view | the chain view ↔ the module picked | MACROS | add the type picked (on a module: back in) | take the module out (on a module: bypass) | the module shown reset |
| <kbd>GLO</kbd> | VOICE, GLOBAL | PERFORM, latched | PERFORM | PERFORM, latched | PERFORM let go | VOICE or GLOBAL reset |
| <kbd>SCL</kbd> | SCALE, CHORD | the chords on, off | + a key: the root | the chords on | the chords off | SCALE and the chords reset |
| <kbd>ARP</kbd> | ARP, STEPS | the ARP on, off | | the ARP on | the ARP off | the ARP's settings or steps reset |
| <kbd>SEQ</kbd> | LOOP, CLIP, TRACK | the projects | the launch pad | a new clip, 1 bar (PRESETS, SEQ held: its length) | DELETE? the clip; again: deleted | the page's settings reset |

A menu button once opens its menu where you left it; pressed in its own menu, its first page. A latched layer closes
with a tap on its button.

## The other buttons

| Button | Once | Twice | Held | + OCT+ | + OCT− |
| --- | --- | --- | --- | --- | --- |
| <kbd>SAVE</kbd> | the SAVE window (SAVE, SAVE AS NEW, CANCEL) | the browser (in it: back) | (for its OCT) | redo | undo |
| <kbd>REC</kbd> | record on the selected track (an empty clip: a take; a clip: overdub); again: stop | TAKE: what you just played, as a clip | the MOD layer | the MOD layer latched | the MOD layer let go |
| <kbd>PLAY</kbd> | the transport on, off | | | | |
| <kbd>OCT−</kbd> <kbd>OCT+</kbd> | the keys' octave, −3 to +3 | | both held 5 s: backup mode (UBOOT) | | |

- <kbd>GLO</kbd> held + <kbd>PLAY</kbd> tapped three times or more: **tap tempo**.
- <kbd>HOME</kbd> held while switching on: start without the last sound.
- In the presets' list: <kbd>SAVE</kbd> twice loads, <kbd>SAVE</kbd> + <kbd>OCT+</kbd> saves as new (named),
  <kbd>SAVE</kbd> + <kbd>OCT−</kbd> deletes (asked first).
- In the browser: <kbd>SAVE</kbd> renames (NAME IT); <kbd>OCT−</kbd> held 3 s deletes the user preset playing;
  <kbd>SAVE</kbd> + <kbd>OCT−</kbd> straight after puts it back.
- On NAME IT: the keys type, <kbd>OCT+</kbd> numbers and symbols, <kbd>OCT−</kbd> deletes, <kbd>SAVE</kbd> writes,
  <kbd>HOME</kbd> leaves.

## The knobs and encoders

| Control | Does |
| --- | --- |
| KNOB 1 to 4 | the four values on the screen (their numbered handles) |
| SELECT | the next or previous module of the menu (on HOME: the track; on the chain view: the slot; in the tables' and drum presets' lists: the category) |
| ALGORITHM | the next or previous page of the module (in the assign window: its two pages) |
| PRESETS | the sounds' list; on the looper's pages, the track; on a drum track, the drum; in a list, the entry |
| MASTER | the output level |

## The layers (while held)

| Layer | Button | Knobs | Keys |
| --- | --- | --- | --- |
| MOD | <kbd>REC</kbd> | the source's depth on each knob's parameter | white keys pick the source: F3 ENV 1, G3 ENV 2, A3 LFO 1, B3 LFO 2, C4 to F4 MACRO 1 to 4, G4 VELOCITY, A4 NOTE, B4 RANDOM, C5 ALTERNATE, D5 MOD WHEEL, E5 BEND, F5 AFTERTOUCH, G5 EXPRESSION |
| PERFORM | <kbd>GLO</kbd> | bend, mod wheel, GLIDE, VOLUME | play |
| MACROS | <kbd>FX</kbd> | MACRO 1 to 4 | F3 to F4: the chain's modules 1 to 8 in or bypassed |
| MOMENTARY | <kbd>LFO</kbd> | the page's values, for now: let go and they go back | play |
| LAUNCH PAD | <kbd>SEQ</kbd> | | white 1-8 the tracks' clips, 9-16 scenes A-H; black 1-8 MUTE, C#5 STOP ALL, D#5 SOLO, F#5 UNDO PASS |

## The keys elsewhere

- **CLIPS page**: white keys 1-8 launch this scene's clips, black keys 1-8 the scenes.
- **A drum track**: white keys 1-8 the drums, 9-16 accented, F#3 DUCK.
- **GRID, HIT**: white keys the sixteen steps, black keys the row (1 KICK to 9 DUCK).
- **NAME IT**: F3 to F#5 A to Z, G5 a space.
- **<kbd>SCL</kbd> held**: a key sets the scale's root.
