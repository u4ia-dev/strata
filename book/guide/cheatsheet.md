# Cheat sheet

**Twice**: two presses within 300 ms. **Held**: held past the HOLD time (400 ms by default). **+ OCT+ / + OCT−**: hold
the button, then press OCT+ or OCT−. **+ OCT− 5 s**: hold both for five seconds; a countdown shows from 2 s, and
letting go of OCT− stops it.

## Menu buttons

| Button | Once | Twice | Held | + OCT+ | + OCT− | + OCT− 5 s |
| --- | --- | --- | --- | --- | --- | --- |
| <kbd>HOME</kbd> | HOME: SOUND, MIX 1-4, MIX 5-8 | SETTINGS | help map; 5 s: DEBUG | next sound | previous sound | |
| <kbd>EDIT</kbd> | OSC A, OSC B, SUB, NOISE, FILTER, MATRIX (drum track: DRUM, KIT) | wavetable list (drum track: drum presets; from KIT or HOME: kits) | | module shown on | module shown off | module reset |
| <kbd>ENV</kbd> | ENV 1, ENV 2 | assign window: envelope or macro onto a knob | | | | envelope reset |
| <kbd>LFO</kbd> | LFO 1, LFO 2 | assign window: LFO onto a knob | MOMENTARY | add a point | delete the point | LFO reset |
| <kbd>FX</kbd> | the chain | chain ↔ the effect chosen | MACROS | add the type (on an effect: back in) | remove (on an effect: bypass) | effect reset |
| <kbd>GLO</kbd> | VOICE, GLOBAL | PERFORM, latched | PERFORM | PERFORM, latched | close PERFORM | VOICE or GLOBAL reset |
| <kbd>SCL</kbd> | SCALE, CHORD | chords on/off | + a key: set the root | chords on | chords off | scale and chords reset |
| <kbd>ARP</kbd> | ARP, STEPS | ARP on/off | | ARP on | ARP off | ARP settings or steps reset |
| <kbd>SEQ</kbd> | LOOP, CLIP, TRACK | projects | launch pad | new 1-bar clip (keep SEQ held, turn PRESETS: length) | delete the clip (asks; press again) | page settings reset |

A latched layer closes with a tap on its button.

## Other buttons and controls

<div class="cols"></div>

| Button | Does |
| --- | --- |
| <kbd>SAVE</kbd> | SAVE window: SAVE, SAVE AS NEW, CANCEL |
| <kbd>SAVE</kbd> twice | the browser (again: back); in a list: load |
| <kbd>SAVE</kbd> + <kbd>OCT−</kbd> / <kbd>OCT+</kbd> | undo / redo |
| <kbd>REC</kbd> | record or overdub on the selected track; again: stop |
| <kbd>REC</kbd> twice | TAKE: what you just played becomes a clip |
| <kbd>REC</kbd> held / + <kbd>OCT+</kbd> | MOD layer / latched |
| <kbd>PLAY</kbd> | transport on/off |
| <kbd>GLO</kbd> held + <kbd>PLAY</kbd> ×3 | tap tempo |
| <kbd>OCT−</kbd> / <kbd>OCT+</kbd> | keys' octave, −3 to +3 |
| <kbd>OCT−</kbd> + <kbd>OCT+</kbd> 5 s | backup mode (USB BOOT) |
| <kbd>HOME</kbd> held at power-on | start without the last sound |

| Control | Does |
| --- | --- |
| KNOB 1–4 | the four values on the screen (numbered handles) |
| SELECT | next module; on HOME: the track; on the FX chain: the slot; in a list: the category |
| ALGORITHM | next page; in the assign window: its second page |
| PRESETS | the presets list; on looper pages: the track; on a drum track: the drum; in a list: the entry |
| MASTER | output level |
| In a list | PRESETS moves, <kbd>SAVE</kbd> twice loads, <kbd>SAVE</kbd> + <kbd>OCT+</kbd> saves new, <kbd>SAVE</kbd> + <kbd>OCT−</kbd> deletes (asks first) |
| NAME IT | keys type (F3–F#5 A–Z, G5 space), <kbd>OCT+</kbd> symbols, <kbd>OCT−</kbd> deletes, <kbd>SAVE</kbd> writes |
| Browser | <kbd>SAVE</kbd> renames; <kbd>OCT−</kbd> held 3 s deletes the user preset playing; <kbd>SAVE</kbd> + <kbd>OCT−</kbd> right after: undelete |

| --- | --- | --- |

| <kbd>SCL</kbd> held | set the root | set the root |
| MOD sources | F3 ENV 1, G3 ENV 2, A3 LFO 1, B3 LFO 2, C4–F4 MACRO 1–4, G4 VELOCITY, A4 NOTE, B4 RANDOM, C5 ALTERNATE, D5 MOD WHEEL, E5 BEND, F5 AFTERTOUCH, G5 EXPRESSION | |
