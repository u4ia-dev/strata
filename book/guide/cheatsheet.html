Cheat sheet

Cheat sheet

Twice: two presses within 300 ms. Held: held past the HOLD time (400 ms by default). + OCT+ / + OCT−: hold the button, then press OCT+ or OCT−. + OCT− 5 s: hold both for five seconds; a countdown shows from 2 s, and letting go of OCT− stops it.

Menu buttons

Button Once Twice Held + OCT+ + OCT− + OCT− 5 s
HOME HOME: SOUND, MIX 1-4, MIX 5-8 SETTINGS help map; 5 s: DEBUG next sound previous sound
EDIT OSC A, OSC B, SUB, NOISE, FILTER, MATRIX (drum track: DRUM, KIT) wavetable list (drum track: drum presets; from KIT or HOME: kits) module shown on module shown off module reset
ENV ENV 1, ENV 2 assign window: envelope or macro onto a knob envelope reset
LFO LFO 1, LFO 2 assign window: LFO onto a knob MOMENTARY add a point delete the point LFO reset
FX the chain chain ↔ the effect chosen MACROS add the type (on an effect: back in) remove (on an effect: bypass) effect reset
GLO VOICE, GLOBAL PERFORM, latched PERFORM PERFORM, latched close PERFORM VOICE or GLOBAL reset
SCL SCALE, CHORD chords on/off + a key: set the root chords on chords off scale and chords reset
ARP ARP, STEPS ARP on/off ARP on ARP off ARP settings or steps reset
SEQ LOOP, CLIP, TRACK projects launch pad new 1-bar clip (keep SEQ held, turn PRESETS: length) delete the clip (asks; press again) page settings reset

A latched layer closes with a tap on its button.

Control Does
KNOB 1–4 the four values on the screen (numbered handles)
SELECT next module; on HOME: the track; on the FX chain: the slot; in a list: the category
ALGORITHM next page; in the assign window: its second page
PRESETS the presets list; on looper pages: the track; on a drum track: the drum; in a list: the entry
MASTER output level
In a list PRESETS moves, SAVE twice loads, SAVE + OCT+ saves new, SAVE + OCT− deletes (asks first)
NAME IT keys type (F3–F#5 A–Z, G5 space), OCT+ symbols, OCT− deletes, SAVE writes
Browser SAVE renames; OCT− held 3 s deletes the user preset playing; SAVE + OCT− right after: undelete
