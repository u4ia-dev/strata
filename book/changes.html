Changes

Changes

What each version changed, newest first.

Book rewritten: condensed, one-page guide

The book now matches Strata V0.87 at commit 3f869d7. The Guide is one page of feature cards, the cheat sheet is laid out wide, and the Manual is shorter, with steps first. SCL's unused MIDI page is gone from the firmware.

V0.87

Drums. Any drum row can use any of seven models (ANALOG, PUNCH, FM, CHIP, NOISE, METAL, WAVE), on DRUM's new MODEL page. 64 factory drum presets in eight categories (EDIT twice on DRUM), six factory kits (808, 909, LO-FI, VIDEO GAME, TRAP, DRUM & BASS: EDIT twice on KIT or HOME), and your own library of 64 drum presets and 16 kits. EUCLID fills a row with a Euclidean rhythm.

Interface.

  • SAVE opens the SAVE window (SAVE, SAVE AS NEW, CANCEL).
  • ENV or LFO twice opens the assign window, with a POLARITY for each matrix slot.
  • Resets are a menu button + OCT− held 5 s.
  • HOME twice opens SETTINGS, which gained WIPE and LIGHTS; HOME held 5 s opens DEBUG.
  • EDIT twice opens the wavetable list. The MATRIX moved to EDIT.
  • Looper: tracks as rows on CLIPS, SONG on LOOP, the projects as a list (SEQ twice), new and deleted clips with SEQ + OCT+ / OCT−, TAKE (REC twice), tap tempo (GLO held + PLAY).
